# Disciplines

Thematic groupings of research topics across v5, v6, v7.

The ten phases below are the v5-author's canonical study sequence — each discipline is
a coherent cluster of topics that reinforce each other. v6 topics are placed according
to their `Likely v5 Phase` metadata in the v6 master table; v7 topics (creators,
seminal texts, crafts, disciplines, emerging tech) are mapped thematically.

Topic names inside each `### Topics` list are matched against the corresponding
topic nodes at parse time (same resolver as the `Connects to:` lines in the
source markdowns). A row that cannot be resolved renders in a faded "unresolved"
state in the UI so curation errors are visible.
