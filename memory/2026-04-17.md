# 2026-04-17 — Built the Research Topics Explorer

## Goal
Static, no-server visualization tool for the 162 research topics curated in `research-topics-v5.md`, `v6.md`, `v7.md`. Must open by double-clicking `index.html` (no dev server, no build step beyond a one-shot parse).

## What was built

```
parse.mjs       Node script. Reads the three MD files, normalizes topics +
                connections, resolves them to a graph, emits data.js
data.js         Generated. window.RESEARCH_DATA = { topics, edges, stats, creators }
index.html      Single-file SPA. Dark theme. 5 views, shared filter sidebar
                + side panel. D3 + marked from CDN. URL hash deep-linking.
README.md       Quick start, regenerate instructions, architecture
LICENSE         MIT (digster)
.gitignore      macOS / editors / playwright artifacts / node_modules
CLAUDE.md       Empty per repo convention
PROMPT.md       Prompt log
```

## Five views

1. **Graph** — D3 force layout, node size = in-degree, color by version (v5 blue, v6 purple, v7 teal). Click highlights neighborhood.
2. **Roadmap** — v5's 10-phase study plan as horizontal swimlanes, v6 additions overlaid (faded purple) at their `likelyPhase`.
3. **Cards** — searchable / sortable grid (name, in-degree, out-degree, version, tier).
4. **Hubs** — top 30 by in-degree / out-degree / cross-version "bridge score" with bar charts.
5. **Creators** — subgraph of v7 Group A thinkers + everything they reference.

Side panel renders the selected topic's full markdown description, key figures, outgoing chips, and incoming references — all chips clickable.

## Parse stats
- 162 topics parsed (v5=56, v6=35, v7=71)
- 588 resolved edges, 278 unresolved (most reference broad fields like "biology", "economics" with no dedicated topic)
- 23 v7 creators identified for the Creators view

## Important parser notes
- v5 topics use `**Connects to:**`; v7 uses `*Resonates with:*` — both handled
- v5/v6/v7 master tables are the authoritative source for tier/phase/idCode/pitch metadata; parser does prefix-fallback when heading and master-table name differ ("PC Revolution" vs "Personal Computer Revolution")
- Connection resolution is token-aligned (prefix or suffix) — earlier substring matching mis-resolved bare "Architecture" → "Information Architecture"
- Alias table for HCI, ML, DSP, GEB, SICP, etc. "AI" maps to ML (closest v5 topic)

## Where to edit
- Visual style → `:root` CSS variables at top of `index.html`
- Add new view → add a tab button in `<nav class="tabs">`, a `<div id="..." class="view">`, and a `render*()` function dispatched by `renderCurrentView()`
- Adjust connection resolution → `resolveConnection()` and `aliases` table in `parse.mjs`
